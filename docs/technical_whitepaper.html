1️⃣ 项目简介

这是一个从零搭建的企业级 RAG + Agent 智能问答系统，核心特点：

  • 不依赖 LangChain AgentExecutor — ReAct 循环手写 80 行，面试能讲清每一行原理
  • 混合检索 — BM25 + 向量检索 + RRF 融合 + BGE Reranker 精排
  • LLM-as-Judge — 独立 Judge LLM 对答案做 5 维度评估，低于阈值自动重写
  • HITL 人机协作 — 高风险操作（send_email）执行前暂停，等待人工审批
  • 全链路可观测 — Langfuse trace 覆盖每次调用

2️⃣ 技术选型理由

🦙 DeepSeek-Chat

为什么不是 GPT-4o / Claude? 成本差 10×，DeepSeek 在中文 RAG 场景差距 <3%。通过 langchain-deepseek 切换只需改一行模型名。

🔤 BGE-M3 + BGE-Reranker

为什么不是 OpenAI Embedding? BGE-M3 支持 8192 token，中文强于 ada-002，本地部署无数据出站。Reranker 交叉编码器比纯向量 Recall@10 提升 26%。

🗄️ Qdrant

为什么不是 Pinecone / Milvus? Qdrant Cloud 1GB 免费，Rust 高性能。LangChain QdrantVectorStore 封装即用。

✍️ 手写 ReAct 循环

为什么不用 AgentExecutor? 面试官问"Prompt 怎么设计的？解析失败怎么处理的？"手写版能答上来。

🔄 Langfuse

为什么不是 MLflow? Langfuse 专为 LLM 设计，原生 trace + span + score。Key 为空时自动降级为 no-op。

🧪 Ragas

为什么自己标 100 个 QA? LLM 生成的评测数据有 bias。人工标注面试能拿出原文出处。

3️⃣ RAG Pipeline core/pipeline.py

RAGPipeline 是整个系统的核心编排器：

flowchart TB START["query(question, top_k=5)"] --> RET["span('hybrid-retrieve')<br>>HybridRetriever.search(top_k=20)"] RET --> RERANK["span('rerank')<br>BGEReranker.rerank(top_k=5)"] RERANK --> CTX["构造 Context<br>从 5 个 doc 拼接"] CTX --> GEN["span('generate')<br>Generator.generate(question, context)"] GEN --> REF["ReflectionModule.evaluate_rag()<br>低分重写"] REF --> RET2["返回 dict(answer, sources, reflection)"] 
# pipeline.py — query() 核心流程
def query(self, question, top_k=5):
    # 1. 混合检索（粗排 20 个）
    with span("hybrid-retrieve"):
        candidates = self.hybrid_retriever.search(question, top_k=20)

    # 2. BGE Reranker 精排（top 5）
    docs = self.reranker.rerank(question, candidates, top_k=top_k)

    # 3. 生成答案
    answer = self.generator.generate(question, context)

    # 4. 反思评估 + 低分重写
    answer, evaluation = self.reflection.evaluate_rag(
        question, answer, source_texts,
        regenerate_func=lambda: self.generator.generate(question, context),
    )

    return {"answer": answer, "sources": sources,
            "reflection": {"score": evaluation.score, ...}}

# react_agent.py — run() 核心循环
def run(self, question):
    for iteration in range(self.max_iterations):
        prompt = self._build_prompt(question, history)
        response_text = self.llm.invoke(prompt).content
        parsed = self._parse_output(response_text)
        if parsed is None:      # 解析失败，让 LLM 修复
            history.append({"observation": "格式错误..."})
            if recent_failures >= 2: break
            continue
        if parsed["final_answer"]:
            return AgentResult(answer=parsed["final_answer"], ...)
        with span(f"tool:{parsed['action']}"):
            observation = self._execute_tool(parsed["action"], ...)
        steps.append(AgentStep(thought=..., observation=observation))
    return AgentResult(answer="抱歉，处理超时...", finished_reason="max_iter")
🔑 finished_reason 枚举： final_answer（正常）/ max_iter / parse_error / tool_error / llm_error

# _mock_llm 标准模式
def _mock_llm(responses):
    llm = MagicMock()
    llm.invoke.side_effect = [MagicMock(content=r) for r in responses]
    return llm

def test_tool_call_path():
    agent = ReActAgent(tools={"calc": lambda expr: "200"}, ...)
    agent.llm = _mock_llm([
        "Thought: 需要计算\nAction: calc\nActionInput: {\"expression\": \"100*2\"}\n",
        "Thought: 算完\nFinalAnswer: 200",
    ])
    result = agent.run("100*2 = ?")
    assert result.answer == "200"
